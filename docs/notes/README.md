# Working notes

Research, design, and campaign material — **not** user-facing documentation
(see `../README.md` for that). Older files may reference code layouts or bug
ledgers that no longer match current state; each carries its own context.

## Campaign / analysis records

| File | What it is |
|------|------------|
| `AGENT_TEST_BUGS.md` | agent-driven test-campaign bug notes |
| `ALL_BUGS_LIST.md` | consolidated bug list from the campaigns |
| `BUG_ANALYSIS.md` | root-cause analysis write-ups |
| `TEST_RESULTS.md`, `QA_TEST_SUMMARY.md` | test-campaign outputs |
| `FOUND_BUGS2.md` | the campaign bug ledger — **closed** (all entries resolved; reproducers kept) |
| `GAPS.md` | known gaps at the time of writing |
| `PLAN.md`, `DESIGN.md`, `DESIGN_UNIFIED_SERVING.md` | design/planning notes |
| `RESEARCH_FINDINGS.md`, `LEAKCANARY_RESEARCH.md`, `LEAKCANARY_INSPIRED_PROPOSALS.md` | research findings and proposals (LeakCanary comparison) |
| `JOIN_EXPLORATION.md`, `JOIN_IMPLEMENTATION.md` | OQL JOIN design + implementation log |
| `SQL_FEATURES_PROPOSALS.md`, `STRING_METRICS_IDEAS.md` | feature proposals |
| `VISUALIZATION_IDEAS.md`, `_DEFERRED`, `_SUMMARY`, `VISUALIZATION_IDEAS_copy.md` | visualization ideas (main/deferred/summary/copy) |
