hprof-analyzer

Java heap dump analysis — in your browser

The web edition of hprof-analyzer, a fast Rust-based tool for investigating Java OutOfMemoryErrors and memory leaks. Your heap dump never leaves your machine — everything runs locally via WebAssembly.

  • 🔍 Leak suspects, dominator tree & retained sizes
  • 📊 Class histogram, GC roots, allocation sites
  • 🧵 Thread stacks, locals, and per-thread objects
  • 💬 SQL-like OQL query shell with tab-completion
  • 🔒 Fully private — no upload, no server, no telemetry
